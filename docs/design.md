# 设计与交互约定

主任务是从想法、素材或样片进入创作。页面以白色为主，媒介内容是视觉主体；蓝色用于当前状态和主要操作。工作空间按业务项目组织，仅查看历史案例，不承接继续编辑。

颜色：重点蓝 #243BEB（Hermes 官方 #0000F2 的色相从 240° 移至约 233°）；深蓝 #243589；纯白 #FFFFFF；浅灰 #F6F7F9；正文 #242833；次要文字 #69717E。参考：https://hermes-agent.nousresearch.com/ 。不再使用整页蓝色底板。

字体：中文 PingFang SC / Noto Sans SC，标题采用轻字重、紧凑字距；正文常规字重，时间码只使用等宽数字。不下载品牌私有字体。

首页保留输入框和剪辑模板，历史案例移到工作空间。素材分析、样片分析先呈现日期相册，点击素材深入；样片的胶囊结构位于原片上方。生成页先呈现自由生成及八种已有模板的瀑布流，空预览区不伪装成实际样片；选定类型再进入想法、分镜、单镜头生成。

设计复核：不新增全屏仪表盘，不把所有功能做成同等的表单卡。首页的文字与输入是重心；相册的缩略图是重心；样片详情的结构与原片相邻；生成入口的卡片只承担类型选择。仅胶囊结构使用轻浮雕，不推广到整个产品。

动作句：日期组从同一日期标题下展开相册，后面的日期组让位；收起后保留缩略预览。素材卡进入同名详情，返回回到原日期与滚动位置。生成模板进入同名创作页，返回仍落在模板入口。点击结构胶囊只切换节点选中态并定位同一个播放器。

| 状态变化 | 驱动视图 | 保持身份的对象 | 保证 |
|---|---|---|---|
| 日期展开收起 | 日期标题、相册 | 日期组 | 日期键与 details 状态 |
| 相册进入返回 | 卡片、详情 | 素材 | asset.id 与返回滚动位置 |
| 胶囊定位 | 节点、播放器 | 原视频 | asset.id；不替换播放器 |
| 选创作类型 | 模板、创作页 | 模板与草稿 | skill.id、独立草稿 |
| 自动分析完成 | 相册状态、详情文字 | 素材、活跃媒体 | 原节点局部更新 |

过渡不拉伸大块媒体，不添加无关区域入场动画；减少动态时直接到达。页面不出现密钥配置、内部接口说明或虚构订阅状态。

验收用本机真实浏览器、Playwright 录屏和三帧检查，覆盖正向/返回、快速切换、桌面与窄屏、空状态和失败状态。模型相关测试使用合成素材；不为本轮界面验收新增 H3 视频生成费用。
