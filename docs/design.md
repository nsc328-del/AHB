# 设计与交互约定

主任务是从想法、素材或样片进入创作。页面以白色为主，媒介内容是视觉主体；蓝色用于当前状态和主要操作。工作空间按业务项目组织过往制作的作品，只读播放和下载各成片版本，不承接继续编辑。星尚采集记录独立放在“历史数据分析”。

颜色：重点蓝 #243BEB（Hermes 官方 #0000F2 的色相从 240° 移至约 233°）；深蓝 #243589；纯白 #FFFFFF；浅灰 #F6F7F9；正文 #242833；次要文字 #69717E。参考：https://hermes-agent.nousresearch.com/ 。不再使用整页蓝色底板。

字体：中文 PingFang SC / Noto Sans SC，标题采用轻字重、紧凑字距；正文常规字重，时间码只使用等宽数字。不下载品牌私有字体。

首页上方以轻字重双行标题与导入素材入口建立创作起点，下方是一体化剪辑桌面：桌面左侧为紧凑素材库，右侧为三条缩略图分支；默认收起镜头参数。拖素材到节点中央替换镜头、到镜头间插入，拖节点排序，点击节点在原处展开自然语言输入和镜头参数，确认当前分支后渲染真实预览。文字创作及 3–5 条 AI 候选保留独立入口，过往作品放在工作空间。“素材&分析”统一素材上传、筛选、预览、分析和选择，按天以正放、无边框、左上至右下错位的预览卡片折叠。样片分析独立使用横卡，不按日期分组；文件名可搜索、重命名，卡片直接展示摘要、标签和结构。日期展开后的素材为紧凑信息卡，包含真实媒体类型、状态、摘要、标签与可用段数；无分析时不伪造标签。样片标题加粗，叙事胶囊秒数占满名称与时间码的两行高度。样片详情依据组织方式展示胶囊或画面序列、截图、原片及内容面板，时间码统一精度与列宽，点击节点定位同一播放器。

生成页为自由生成和八模板的小卡片，默认纸艺定格解说。完整显示九个紧凑卡片，再在模板网格下方展开页面内双栏，左侧描述与片段脚本、右侧当前模板动态预览；没有弹窗、遮罩或独立滚动层。按钮为“生成方案”，DeepSeek 结合完整 H3 prompting＋模板 Skill 按切镜出稿。修改脚本或时长会要求同步提示词，片段确认状态持久化。九个模板标记使用统一线性图标，淡底蓝线与蓝底淡线在200ms内反转，图标节点保持身份；关闭与快速切换从当前状态回退。新描述留空并显示各模板提示，历史方案默认折叠。参考素材在当前字段下上传/拖入或展开库内缩略图网格；已选项为缩略图与右上角移除按钮，异步上传绑定原模板和原输入槽位。

“确认全部并生成”先显示预计总费用，冻结当前审阅版本的顺序、脚本、提示词、输入素材及画面参数，再创建各片段任务。片段全部成功后，以 FFmpeg 统一画幅、帧率与音轨并按顺序拼接，不追加模型请求。单段重生成仅替换该段，沿用其他已完成任务，另存整片版本。快照与当前脚本不一致的片段标记待更新。失败只重试明确失败的段；只有拼接失败时本地重拼、预计费用为零；回执未知不自动重发。同方案有未完成或未知结果时禁止另发付费批次。提交编号防止重复点击，重启不自动重发收费请求。各段保留实际用量胶囊，完整视频不重复累计子片段用量。

历史数据页左列固定项目导航，右侧直接进入数据可视化，不先打开工作区卡片。默认星尚／抖音，平台切换、账号与发布日期筛选围绕同一个看板工作。主视觉为按发布时间排列的单条视频播放散点，配合发布数量、播放分布和互动构成；明细退后，仍可直接进入采集记录。桌面项目列纵向排列，窄屏改为上方横向导航。蓝色承担数据强调，正文、日期、采集范围与缺失标记用灰色建立层级，不用多色平台混合评分。

候选页以分支图和实际预览为重心。一批为 3、4 或 5 条可播放候选，画面、素材区间、字幕、声音与其他播放参数一致的连续开头才可共用节点；没有共同开头就呈现多棵树，不强造主轴，不把分叉后的相同镜头重新合流。节点表示实际镜头，末端表示完整候选。点击节点定位预览，点击末端切换成片；窄屏用逐条分支与镜头序列保留可操作性。

每批固定 1 条探索片，并通过同一套素材、时间线和预览输出检查。结构差异基于取材、次序和时长分配，不靠标题或字幕改名。历史结构相似度仅作轻量排序降权，最大扣 0.08；无可比较历史时，新颖度与相似度为空。规则属于结构启发式，不代表表现预测或审美评价，没有模型训练；历史采集文案和表现数据留在本机，不进入该排序。全部预览成功后才开放最终选择，采用前需查看对应候选；人可以选择任意候选或全部不采用，探索片不被排序淘汰。

设计复核：历史数据页拥有独立可视化工作面，不将仪表盘扩散到创作首页，也不把所有功能做成同等的表单卡。首页的分支关系、素材与当前镜头是重心；相册的缩略图是重心；样片详情先读结构和画面，再对照下方原片与内容面板；生成入口的卡片只承担类型选择；候选页先看分支关系再看成片。胶囊结构与用量胶囊使用轻浮雕，不推广到整个产品。

动作句：日期组的预览卡片保持正放，以平移轻轻收拢，相册在同一日期标题下展开，后面的日期组让位；收回到斜向错位卡片堆，快速反向由当前视觉状态继续，不重建卡片。素材卡进入同名详情，返回回到原日期与滚动位置。生成模板在网格下方的页面内展开为同名工作区，收起后焦点回到原卡片；展开使用短距离位移与淡入，模板样片在脚本提交、修改与确认期间保持同一节点。点击结构胶囊只切换节点选中态并定位同一个播放器；镜头、声音、剪新片标签只切换右侧内容。用量明细从胶囊旁展开，后续回执更新数字，不替换弹层、不抢焦点。历史图表在同一筛选栏下更新，项目导航保持原位；点击散点或明细打开右侧采集记录，关闭回到原图。候选节点与分支末端驱动下方预览，任务进度只更新相关候选，已在播放的预览不因进度刷新重建。

| 状态变化 | 驱动视图 | 保持身份的对象 | 保证 |
|---|---|---|---|
| 日期展开收起 | 层叠预览、日期标题、相册 | 日期组、预览卡片 | 日期键、展开状态、原卡片 DOM |
| 相册进入返回 | 卡片、详情 | 素材 | asset.id 与返回滚动位置 |
| 胶囊定位与内容切换 | 节点、截图、内容标签、播放器 | 原视频 | asset.id；不替换播放器 |
| 查看实际用量 | 胶囊、明细浮层 | 作用域与同一明细面板 | project/asset/job id；异步更新不重建、不移动焦点 |
| 选创作类型 | 卡片、居中双栏 | 模板标题、入口与草稿 | skill.id、关闭焦点返回与独立草稿 |
| 审阅片段 | 中文脚本、提示词、确认状态 | 片段与原 AI 记录 | job.id、shot.id、revision；编辑取消确认，提示词同步后才能确认 |
| 自动分析完成 | 相册状态、详情文字 | 素材、活跃媒体 | 原节点局部更新 |
| 作品浏览 | 业务分组、作品卡、成片详情 | 作品与渲染版本 | project.id、render.id；只读路由与创作路由独立 |
| 历史筛选 | 平台、日期控件与图表 | 项目导航、筛选栏 | 局部图表更新；请求序号和路由校验 |
| 查看采集记录 | 散点或视频标题、侧栏 | 发布视频 | publication.id；关闭回到原图 |
| 候选进度更新 | 分支状态、预览状态 | 候选批次与活跃播放器 | batch.id、plan.id、render.id；进度更新不替换同一播放器 |
| 候选采用 | 分支末端、当前方案 | 被采用的方案与预览成片 | 选择事件与当前版本同时保存；未选择不激活 |

用量以供应商实际回执为来源，缺失与早期未记录明确区分，部分 Token 或仅秒数不冒充完整总量；缓存率只使用同时有输入与缓存字段的记录。

过渡不拉伸大块媒体，不添加无关区域入场动画；减少动态时直接到达。页面不出现密钥配置、内部接口说明或虚构订阅状态。

验收应使用本机真实浏览器、Playwright 录屏和三帧检查，覆盖正向/返回、快速切换、桌面与窄屏、空状态和失败状态。历史看板需检查跨平台隔离、北京时间、累计口径、缺失与约数；候选需检查真实共享前缀与独立开头、全部预览成功后人工选择、单条渲染失败重试及播放器身份。完成情况以实际验收记录为准，不以本设计文档代替验证。模型相关测试使用合成素材，不为界面验收新增 H3 视频生成费用。

分段审阅保存覆盖字段，原模型结果保留；异步提示词更新前后都校验版本，不能覆盖更新期间的新修改。生成去重基于片段与实际参数，其他片段的确认不会触发再次收费。

## 首页节点输入

动作句：选中的镜头卡从原图与标题锚点展开，后续节点向右、下方分支向下让位；收起回到原节点，连线跟随布局。节点内先写要求，再由 AI 应用到当前镜头；手动参数变化即时保存草稿。展开对象保持 clip.id，分支选择保持 branch.id，播放器保持 render.url；输入时不重建整张画布。共享开头只是相同播放内容的视觉合并，修改只落在当前分支。

AI 请求包含当前允许素材和相邻镜头上下文，不发送整库。提交编号持久化防重复调用；结果仅能改一个镜头，返回时校验输入快照。期间任何编辑都会令旧结果失效，不覆盖新输入。当前支持素材、取材区间、时长、字幕和 cut/fade，不承诺生成新画面或变速。镜头 AI 与最终 FFmpeg 渲染分开确认，用量胶囊展示实际调用。

样片内容段与实际检测镜头分别选中与定位，原播放器保持唯一。长片的渐变候选标为待核对，不伪装成确认切点。窄屏允许顺序布局与画布内部滚动，桌面以结构、截图、播放器及右侧内容面板构成一个工作面。

首页拖拽动作句：素材从抓取位置浮起，原卡留位，目标节点高亮或插入位置张开；松手后预览落入目标，再呈现落定反馈。拖出画布或取消则回到原位。命中使用未被预览位移污染的几何位置，缩放和平移后重新换算坐标；指针移动不重建画布。分支保持 branch.id，排序保留 clip.id，新增镜头获得新 clip.id；取消、失焦与离开路由清理监听和动画。键盘按钮仍可完成选择、插入、前移、后移和撤销。


## 动画短片

动作句：在素材生成内进入动画工作面，确认的片段从描述下方展开；单段修改在原片段下展开，右侧播放器按所选输出 URL 保持同一个节点。版本切换读取对应源工程，历史版本只读。素材与作品中的动画入口指向确切的 animation_id/revision_id；“放入剪辑”把成片追加到当前分支，保留已编辑镜头。

DeepSeek 写分段方案与自包含动画源码，程序不以手工画面替代模型输出。renderAt(t) 要支持乱序定位；隔离浏览器在固定画幅/30fps下逐帧渲染，检查时间确定性、空白帧、执行错误与越界文字。实际关键帧经 DeepSeek 核对，失败最多修正一次，成功片段与原始回复保留，恢复只执行缺失步骤。浏览器使用独立临时目录、沙箱与无网络内容策略，源码不在工作台同源执行。

方案版本、场景ID、输入、源码指纹、原始模型回执、渲染耗时、输出素材、父版本和任务用量分别保存；一个段落修改不改变其他段或旧成片。未知提交用相同UUID查询原请求，任务晚返回不覆盖新头版本。下载工程为JSON附件；普通API不返回源码或私密路径。动画结果登记到常规素材、作品与渲染版本体系，不重复执行一次成片渲染。

已有源码的修改由DS返回唯一文本锚点的局部替换，程序原样应用并校验，不用整页重写代替局部改动。原始回复与补丁单独存档。视觉复核结合实际采样时刻与可见DOM文字，禁止从早于字幕入场的帧推断字幕缺失；未采样区间不算已观察证据。程序确定性检查同时比较画面和完整渲染状态，仅在状态完全相同且像素差不超过1/255、影响面积不超过0.1%时将字体栅格化差异记为警告。

## 样片组织方式

叙事才显示内容推进胶囊；运动衔接显示场景缩略图及相邻连接点；声音节奏主导显示镜头时长条；并列或待判断结果保持中性镜头序列，不借旧结构角色补齐。分类依据内容与连接证据，不按视频时长分配模板。点击连接原位展开两侧证据与时间，使用同一个播放器；连接线不画物理运镜方向箭头。`source_analysis_id`是输入溯源，不与发布后新的容器版本ID相等；失效由后端清除当前presentation处理。
