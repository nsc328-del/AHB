# 当前测试数据

项目负责人于 2026-10-22 要求将当前测试内容公开，排除星尚历史数据，并确认网络视频与配乐已取得公开再分发授权。仓库 `demo/` 保存这一批测试快照；它不是新生成的示例，也不包含开发者的模型密钥。

## 使用

克隆仓库、安装 README 所列依赖后，在项目根目录执行：

```sh
.venv/bin/python scripts/demo_data.py import --data-dir data
VIDEO_STUDIO_DAILY_SUMMARY=0 .venv/bin/python app.py
```

导入只允许使用空目标目录，不覆盖已有素材和作品。已有个人数据时，选择新的目录：

```sh
.venv/bin/python scripts/demo_data.py import --data-dir tmp/demo-workspace
VIDEO_STUDIO_DATA="$PWD/tmp/demo-workspace" VIDEO_STUDIO_DAILY_SUMMARY=0 .venv/bin/python app.py
```

不要同时运行两份服务占用同一端口。浏览已有测试结果不需要配置模型；点击重新分析、生成方案、AI 修改或 H3 生成仍会涉及真实服务。关闭后台日汇总不是全局禁止模型调用的开关。

打开工作台后可以查看几何素材、网络长短样片、餐饮和咖啡测试、蛋包饭动作剪辑、H3 蓝色方块，以及 HTML 动画的原片、分析和历史成片。「工作空间 → 餐饮实测」保留餐厅、咖啡及蛋包饭的原有记录。

旧实验的失败、未采用候选和缺失证据仍保持原状态。四条早期成片没有冻结渲染清单，可以播放，但不补造剪辑拆解。文件和记录清单以 `demo/manifest.json` 为准。

## 保留与排除

- 媒体不重编码，不换成占位图；保留素材、样片、成片与版本、动画源文件、分析、任务结果、候选状态及实际用量。
- 星尚的发布记录、观测、同步与关联表不进入快照；导入时重新建立空表，不复制原 SQLite 的空闲页或备份。
- 混有星尚历史数据的开发截图、录屏、报告或数据库备份留在本机，不为公开而修改其中的原始业务证据。
- 密钥、账户配置、浏览器登录信息和访问签名不进入数据包。必要的路径重定位和脱敏单列记录；分析内容、时间码、ID 与真实执行结果不人工修正。
- 源数据中的本机路径在快照内表示为可迁移引用，导入时指向新目录。原素材和成片的内容哈希保持一致。

历史报告里已经不存在的工作树或临时环境路径只保留去除用户名后的历史引用，不当作当前文件；与可导入的素材路径分开记录。`manifest.json` 中的路径转换和脱敏清单便于核对这些必要变化。

快照与运行目录分开：`demo/` 是可复核的发布版本，`data/` 或指定目录是本机可写工作数据。后续本机修改不会自动改动仓库快照。

## 验证边界

导出与导入检查应确认排除表为空、记录关系保留、文件哈希一致、跨目录后预览与成片可用。原本不存在的失败任务临时输出只保留失败记录，不伪造文件。数据快照用于重现已保存的测试结果，不证明真实门店素材上的普遍剪辑质量，也不会替新用户取得模型账号、星尚数据源或第三方平台权限。
