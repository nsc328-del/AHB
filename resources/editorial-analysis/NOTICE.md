# 来源与适配范围

本目录是工作台的已有视频分析规则，不安装上游命令、外部采集服务或作者个人配置。

- Melvynx / video-agent-skills，`skills/studio-script/references/script-rules.md`：仅取内容类型阅读角度与事实约束。没有采用固定换镜间隔、英语语速、传播评分或创作交付流程。
  - https://github.com/Melvynx/video-agent-skills/blob/main/skills/studio-script/references/script-rules.md
  - https://github.com/Melvynx/video-agent-skills/blob/main/LICENSE
- zenstory-ai / drama-skills，`skills/short-drama-review/references/review-method.md` 及 `anti-template-repair.md`：仅取位置与证据优先、机械一致性先查、区分事实与审美、保留有意重复。
  - https://github.com/zenstory-ai/drama-skills/blob/main/skills/short-drama-review/references/review-method.md
  - https://github.com/zenstory-ai/drama-skills/blob/main/skills/short-drama-review/references/anti-template-repair.md
  - https://github.com/zenstory-ai/drama-skills/blob/main/LICENSE

`thatjuan/video-script` 未发现明确仓库许可，本次仅作阅读比较，不复制或加载其文本。其镜头服务整体结构的方法与上述工作台规则目的重合，不增加第二套创作结构。
