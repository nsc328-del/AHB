# 通用视频 AI 剪辑工作台

本机入口：[http://127.0.0.1:8787](http://127.0.0.1:8787)。双击 `start.command` 打开；服务在终端中运行，关闭终端会停止。再次打开沿用素材、作品和任务记录。

界面以白底为主，蓝色用于当前状态和主要操作；媒体内容保留自己的颜色。页面没有密钥配置入口。

## 使用

- **开始剪辑**：写需求、添加或选取素材、选模板和比例，生成方案。进入作品后继续对话修改，点击镜头调整来源、入点、时长、字幕和位置，渲染并下载成片。
- **素材库**：图片、视频和音频保存在项目本地 `data/`。新上传的图片、视频自动在后台排队调用 DeepSeek 分析；有音轨的素材另行进行本机语音转写。上传后可查看任务状态，不必逐个点分析。
- **素材分析**：先浏览按上传日期折叠的相册，再点击素材查看标签、画面摘要、片段时间码和语音转录。可选整份素材或指定片段带入剪辑；返回相册保留展开状态与原卡片位置。
- **样片分析**：上传样片后自动排队拉片，按日期收入样片相册。进入详情，胶囊形剪辑结构位于原片上方；点击节点定位同一个播放器。填写新主题并选自己的素材，按结构生成方案后自动渲染新片。样片原片不入成片。
- **素材生成**：先从自由生成和八种模板中选择创作类型，再填写想法与参考素材，点“编写脚本”。DeepSeek 读取对应官方 Skill，生成中文脚本、分镜和视频提示词；“使用这个镜头”后可核对提示词、模式、时长与费用，再明确点击“生成这个镜头”提交 H3。生成结果自动入库，类型卡片的预览图暂留空。

九种创作类型为自由生成、极简产品广告、3D 动画短片、纸艺定格解说、品牌宣传片、音乐与字幕、游戏合作开场、纸张拼贴解说、手绘与实拍。画面设置支持文生视频、首帧、尾帧、首尾帧和多模态参考；各类型分别保留草稿。缺少角色、产品图或配乐时，脚本区会列出所需素材。

## 历史、比较与发布表现

从“工作空间”进入按业务组织的案例库，当前已有“星尚”。在其中按平台、账号和标题筛选三平台发布记录，加载更多并查看历次采集。工作空间只读浏览历史案例，不承接作品编辑或加入新创作；历史采集文案、表现数据与观测快照留在本机，不会自动发送给模型。

进入作品后，下方有三个工作面：

- **候选方案**：使用同一份素材和分析生成三个不同结构，展开镜头后可采用，也可全部不采用。生成过程中当前方案不变；采用前会保存正在编辑的内容。候选保存为独立版本，旧稿可回看。生成候选调用 DeepSeek，具有普通方案生成的 API 用量，不调用 H3。
- **选择与修改**：记录看过哪些候选、展示顺序、采用或放弃、可选理由，以及人工/AI 修改的父版本和差异。人工偏好和发布表现独立保存，没有模型训练或自动评分。
- **发布表现**：先选择本项目的一份已渲染成片，再选择平台发布记录并确认它们对应。绑定保存成片 SHA-256、方案版本和确认时间；撤销关联保留历史事件。不会根据标题或“最新生成版”自动推断发布版本，也不会提交平台发布。

“更新采集记录”通过已有 `ssh mini-alpha` 只读导出星尚的 `publication-inventory/publications.sqlite`，写入本机缓存，不启动平台采集、不修改 Alpha 数据或既有定时任务。连接失败时显示失败并保留已导入数据；再次打开页面可继续看本机历史。显式指定 `VIDEO_STUDIO_PUBLICATION_DB=/绝对路径/publications.sqlite` 可读取本地同结构采集库。只读导出遇未合并 WAL 且无法建立普通只读连接时拒绝本次刷新，不导入不一致数据。

截至本次 2026-10-20 验收，已接入 537 条三平台发布记录、4,685 次观测，最近采集为北京时间 10:37。指标显示实际采集时间与发布后间隔；累计播放不是当天新增，各平台分别看，缺失不补零，近似数保留标记。最新快照没有完播率/跳出率时，旧观测仍在“历次采集”中，不与新播放拼接。人均观看时长单位未明确时展示原始值并标记“单位待核”。

新渲染会同时保存 `.manifest.json`，记录实际输出帧边界、素材/成片指纹、方案和渲染器信息，供发布绑定追溯。它不承诺不同机器字体或编码环境下逐字节一致。

## 模型与费用

DeepSeek 与 MiniMax 使用本机后端私密配置，界面只显示服务是否可用。密钥不进入项目源码、数据库和日志；默认只连官方接口。

DeepSeek 使用 `deepseek-flash` 进行图片/抽帧分析和 JSON 方案生成。上传分析、生成方案和分镜会产生相应 API 用量。语音由本机 faster-whisper 转录，首次使用仅下载公开模型权重；自动识别文本应对照原音核对。

H3 在用户点击生成具体镜头后提交。页面显示国内价格估算，使用国际接口时不套用人民币估算。未知提交不重复发送；已取得供应商编号的中断任务可以“查询原任务”。服务重启不会自动重做付费任务。

九个官方 Skills 的原文与引用固定保存在 `vendor/skills/`，附来源和 SHA-256。Hub 的画布、选择卡、分镜与视频生成被适配为本工作台对象；自动锚点生图与独立音乐生成尚未接入，使用上传素材。详见 `vendor/skills/README.md`。

## 实现与运行

FastAPI + SQLite；原件、抽帧、分析版本、剪辑方案、渲染文件和任务分开保存。Python/FFmpeg 读取同一份时间线完成裁切、中心适配画幅、图片推近、字幕、原声/配乐合成。没有剪映或 Computer Use 执行路径。

当前支持直接切入、片段开头黑场淡入；淡入不交叠，不改变总时长。当前成片与方案版本绑定，历史计划和成片保留。

运行环境：Python 3.12、ffmpeg/ffprobe。本机虚拟环境复用已有库并安装独立带 libass 的 imageio-ffmpeg；重建可执行：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```

`VIDEO_STUDIO_DATA` 可指定独立数据目录；默认项目 `data/`。本项目只监听 `127.0.0.1:8787`，没有团队账号、外网部署或自动发布。

后端可读取 `DEEPSEEK_API_KEY`、`MINIMAX_API_KEY` 环境变量或本机私密文件 `~/.config/video-ai-studio/providers.json`；该文件权限应为 0600。已有星尚后端的私密 `server.env` 配置仍可沿用。密钥配置不放进工作台页面，也不随项目交付。

关键检查：

```sh
.venv/bin/python -m unittest discover -s tests -v
node --check static/app.js
```

模型请求模拟检查与真实供应商验收分开记录；当前结果与未覆盖范围见 [验收记录](output/qa/acceptance.json)。最初调研见 `output/产品方案与接入核对.md`。
