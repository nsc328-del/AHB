# 通用视频 AI 剪辑工作台

本机入口：[http://127.0.0.1:8787](http://127.0.0.1:8787)。双击 `start.command` 打开；服务在终端中运行，关闭终端会停止。再次打开沿用素材、作品和任务记录。

界面以白底为主，蓝色用于当前状态和主要操作；媒体内容保留自己的颜色。页面没有密钥配置入口。

## 使用

- **运营首页**：隆莱呷内容日历。年度计划以春节返工、春秋开学、暑期、五一国庆和平台营销季为主线，区分校园、写字楼、商圈门店，仍为可编辑草案；活动需以品牌确认信息为准。近期风向复用星尚的搜搜热公开抖音综合榜，按美食话题、拍法和人群生活场景筛选，保留原标题、聚合榜序位和快照时间；不混入行业新闻、不把综合榜筛选称为垂类榜。小红书与抖音热点宝账号接入暂缓。无适合线索时显示空结果，不用新闻填满；点击刷新，生成选题时超过6小时也会先更新。DeepSeek 结合品牌资料、对应月份计划和来源生成内容：本周补齐尚未排期的日期（当前周从今天起），当日新增3条备选。标题、拍法、镜头、平台、时长和日期可修改并保存到本机 SQLite；版本冲突不覆盖，删除可撤销，再生成不覆盖现有内容。开始制作会携带选题 ID、版本与来源快照进入剪辑，仍须选择素材并主动生成。暂未接团队账号、审核或自动分发。
- **开始剪辑**：以创作入口和一体化剪辑桌面进入，默认收起三条分支的镜头参数。素材拖到节点中央可替换，拖到镜头之间可插入，拖镜头可排序；支持撤销、画布缩放与平移，点开节点填写自然语言要求，由 DeepSeek 修改该镜头；素材、源入点、时长和字幕也可手动调整。确认分支后在本机生成可播放预览，修改后保留上次预览。文字创作入口保留需求、模板和每批 3、4 或 5 条候选选择。系统为每条候选生成实际可播放的预览；全部就绪后，由人查看并采用一条，或全部不采用。采用后可继续对话修改，点击镜头调整来源、入点、时长、字幕和位置，再渲染并下载成片。
- **素材&分析**：统一管理图片、视频和音频。按上传日期显示从左上向右下错位的无边框预览卡片，点击展开相册；支持类型筛选、名称/标签/内容搜索及选择当前素材。点击素材查看预览、标签、摘要、片段与转录，可选整份或指定片段带入剪辑。新上传的图片、视频由后端自动领取分析，有音轨的素材另行本机转写；原件保存在本地 `data/`。返回相册保留展开状态和原卡片位置。
- **样片分析**：每份样片是一张横卡，直接显示缩略图、文件名、标签、摘要与结构节点，支持按文件名搜索和重命名。点击进入完整分析，依据组织方式展示叙事胶囊、运动衔接画面序列、节奏条或并列场景，点击连接可看两侧依据；保留截图和同一个播放器。内容段、镜头、声音、剪新片在面板内切换。实际切镜由本机检测，内容段由模型解释，两者分别计数和显示；候选渐变独立标记待核对。填写新主题并选自己的素材，借用结构生成候选预览，再人工选择。样片原片不入成片。
- **素材生成**：自由生成和八种模板以整齐小卡片排列，默认展开“纸艺定格解说”。九个图标卡片全部在前，展开时图标底色与线条颜色反转；工作区在整个模板网格下方随页面展开，左侧描述与分段脚本，右侧模板动态预览。点“生成方案”，DeepSeek 读取完整 H3 prompting 与对应模板 Skill，按切镜拆成可编辑片段。修改脚本或时长后，先“更新提示词”再确认。核对总费用后“确认全部并生成”，全部完成即按顺序拼为完整视频。单段修改后重新生成会沿用其他已完成片段、自动拼出新版本，旧版保留；失败只重试失败段，未知回执只查询原任务。脚本已改但仍沿用旧片段时明确标记待更新。
- **动画短片**：在“素材生成”右上进入，支持自由动画、文字动效、数据对比、流程解说。DeepSeek 先给出可编辑分段方案，确认后实际编写 HTML/CSS/SVG/Canvas，并在本机按固定时间逐帧导出 MP4。程序检查与 DeepSeek 关键帧核对通过后拼接；每段最多自动修正一次。修改一段只生成该段，其他段复用，旧版保留。动画和单段自动进入素材库，可放入首页分支混剪；从素材、作品可以回到对应动画版本，工程可单独下载。
- **工作空间**：查看本机制作过的作品、播放和下载各成片版本。按作品明确的业务项目归属分组；没有归属的作品显示在“未分组”。未采用的候选预览留在候选批次中；采用后的成片进入作品版本。剪辑作品只读浏览；动画作品另有返回对应源工程的入口，历史版本保持只读。首页不再展示历史作品。
- **历史数据分析**：点击即进入看板，左列按项目切换，右侧展示该项目的发布数据。目前项目为星尚，默认抖音；小红书、视频号单独切换，不合成跨平台表现评分。

九种创作类型为自由生成、极简产品广告、3D 动画短片、纸艺定格解说、品牌宣传片、音乐与字幕、游戏合作开场、纸张拼贴解说、手绘与实拍。画面设置支持文生视频、首帧、尾帧、首尾帧和多模态参考；各类型分别保留本次草稿，新描述默认留空，旧方案单独折叠。参考素材支持上传、拖入和从素材库选取，显示缩略图并可逐个移除，按输入模式检查格式、数量与时长。缺少必需角色、产品图或配乐时，脚本区列出所需素材，补齐重新出稿后才能确认。官方样片来自 MiniMax H3 仓库的八个模板 GIF，只加载当前模板；自由生成不冒用模板样片。

## 历史、比较与发布表现

“历史数据分析”直接展示项目看板，无工作区卡片中转。按平台、账号和发布日期筛选，查看每条视频的播放散点、每日发布数量、播放分布、各类互动累计值，以及播放与完播率中位数。点击散点或视频标题打开该视频的历次采集记录；明细可搜索、排序。图表只使用每条视频最近一次采集值，发布日期与采集时刻统一按北京时间解释。视频的累计播放与发布后观测时长同时保留，不把观测次数当视频数，不把累计快照当日新增。

历史采集文案、表现数据与观测快照留在本机，不发送给模型，不参与当前候选排序。该页与“工作空间”的本机成片浏览独立，不按采集账号推断作品的业务归属。

进入作品后，下方有三个工作面：

- **候选成片**：固定本批素材、分析与转录输入，生成 3–5 个不同结构，并通过 Python/FFmpeg 全部渲染为预览成片。分支图只合并实际播放参数相同的连续开头；开头不同就分成独立树，分叉后不会因后面某个镜头相似而伪装成再次共用。点击分支末端查看候选，点击镜头定位对应预览。全部预览成功、所选候选已被查看后才能采用；生成和排序均不替人选片，也不改变正在编辑的方案。失败预览可单独重试，成功结果保留。候选生成调用 DeepSeek，预览渲染在本机完成，不调用 H3。
- **选择与修改**：记录看过哪些候选、展示顺序、采用或放弃、可选理由，以及人工/AI 修改的父版本和差异。候选、输入快照、规则版本与渲染结果分别保存；采用后继续修改可追溯到原分支。人工偏好和发布表现独立保存，没有模型训练。
- **发布表现**：先选择本项目的一份已渲染成片，再选择平台发布记录并确认它们对应。绑定保存成片 SHA-256、方案版本和确认时间；撤销关联保留历史事件。不会根据标题或“最新生成版”自动推断发布版本，也不会提交平台发布。

每批固定保留 **1 条探索片**，与其余候选在素材次序、取材区间或时长分配上形成明显差异，并通过与普通候选相同的素材、时间线和输出校验。只换标题、字幕、转场，或把同一镜头无意义地拆开，不算探索。当前结构距离阈值为 0.25；它是工程启发式，并不表示观众能感受到“25% 新意”。素材不足以形成有效差异时，本批会明确失败，不用重复视频填满数量。

历史相似度仅比较本机已采用且已渲染的剪辑结构：同一作品，或显式填写相同平台和账号的其他作品，最多取 100 个历史版本。不把星尚采集数据或未采用的候选当作训练样本。相似度按镜头时长分配、数量与转场等计算，对排序分值最多扣 **0.08**；没有可比较历史时，相似度与新颖度为空，扣分为零。该分值只用于候选展示顺序，是**结构启发式，不是播放、留存或创作质量预测**。探索席位始终保留，最终选择始终由人完成。

“更新采集”通过已有 `ssh mini-alpha` 只读导出星尚的 `publication-inventory/publications.sqlite`，写入本机缓存，不启动平台采集、不修改 Alpha 数据或既有定时任务。连接失败时显示失败并保留已导入数据；再次打开页面可继续看本机历史。显式指定 `VIDEO_STUDIO_PUBLICATION_DB=/绝对路径/publications.sqlite` 可读取本地同结构采集库。只读导出遇未合并 WAL 且无法建立普通只读连接时拒绝本次刷新，不导入不一致数据。

2026-10-20 已有本地采集缓存为 537 条三平台发布记录、4,685 次观测，最近采集为北京时间 10:37。指标显示实际采集时间与发布后间隔；各平台分别看，缺失不补零，近似数与零值歧义保留标记。最新快照没有完播率/跳出率时，旧观测仍在“采集记录”中，不与新播放拼接。人均观看时长单位未明确时不纳入聚合；原始值留在采集快照。

新渲染会同时保存 `.manifest.json`，记录实际输出帧边界、素材/成片指纹、方案和渲染器信息，供发布绑定追溯。它不承诺不同机器字体或编码环境下逐字节一致。

## 模型与费用

DeepSeek 与 MiniMax 使用本机后端私密配置，界面只显示服务是否可用。密钥不进入项目源码、数据库和日志；默认只连官方接口。

顶栏显示累计用量；作品、素材详情、分镜与生成结果旁有各自的用量胶囊，点击查看输入、输出、缓存命中和最近调用。只记录供应商实际返回的数值，缺失不补零。视频秒数与 Token 分列，H3 同一任务的重复查询只记一次；有些调用只返回秒数或部分字段，会分别标明。记录从本次启用开始，早期调用显示“未记录”，不会伪造历史用量，也未换算为 credit。

DeepSeek 使用 `deepseek-flash` 进行图片/抽帧分析和 JSON 方案生成。上传分析、生成方案和分镜会产生相应 API 用量。语音由本机 faster-whisper 转录，首次使用仅下载公开模型权重；自动识别文本应对照原音核对。

H3 在用户核对费用并点击整批生成或单段重新生成后提交。页面显示国内价格估算，使用国际接口时不套用人民币估算。未知提交不重复发送；已取得供应商编号的中断任务可以“查询原任务”。服务重启不会自动重做付费任务。

九个官方 Skills 的原文与引用固定保存在 `vendor/skills/`，附来源和 SHA-256。Hub 的画布、选择卡、分镜与视频生成被适配为本工作台对象；自动锚点生图与独立音乐生成尚未接入，使用上传素材。详见 `vendor/skills/README.md`。

## 实现与运行

FastAPI + SQLite；原件、抽帧、分析版本、剪辑方案、渲染文件和任务分开保存。Python/FFmpeg 读取同一份时间线完成裁切、中心适配画幅、图片推近、字幕、原声/配乐合成。没有剪映或 Computer Use 执行路径。

当前支持直接切入、片段开头黑场淡入；淡入不交叠，不改变总时长。当前成片与方案版本绑定，历史计划和成片保留。

运行环境：Python 3.12、ffmpeg/ffprobe。动画逐帧导出另外使用 Playwright 1.64.0 与已安装的 Google Chrome（无界面、独立临时环境、任务结束关闭），不会操作用户浏览器。本机虚拟环境复用已有库并安装独立带 libass 的 imageio-ffmpeg；重建可执行：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```

`VIDEO_STUDIO_DATA` 可指定独立数据目录；默认项目 `data/`。本项目只监听 `127.0.0.1:8787`，没有团队账号、外网部署或自动发布。

后端可读取 `DEEPSEEK_API_KEY`、`MINIMAX_API_KEY` 环境变量或本机私密文件 `~/.config/video-ai-studio/providers.json`；该文件权限应为 0600。已有星尚后端的私密 `server.env` 配置仍可沿用。密钥配置不放进工作台页面，也不随项目交付。

关键检查：

```sh
.venv/bin/python -m unittest discover -s tests -v
node --check static/app.js
```

模型请求模拟检查与真实供应商验收分开记录；当前结果与未覆盖范围见 [验收记录](output/qa/acceptance.json)。最初调研见 `output/产品方案与接入核对.md`。

## 样片分析 v2

本机检测先做相机运动补偿，再识别瞬时画面变化；每个检测镜头内取证据帧，并补充均匀采样及渐变候选附近画面。长片按最多 45 秒、48 帧的窗口分别分析，再汇总内容结构。窗口结果以输入和模型配置指纹持久化，重试复用已完成窗口；复用不新增 Token 记录，来源任务仍可追溯。格式校验失败保留旧分析，不写入半份结果。

有音轨的样片等待本机语音转写完成，再把通过置信度筛选的文本与时间码送入分析。置信度阈值是保守工程门槛，未做准确率校准；不可靠文本保留供核对，但不进入模型判断。检测镜头不等于人工真值，强运动中的切镜、叠化和模型对运镜的文字理解仍需核对。两条真实样片的优化前后结果见 `output/reference-optimization-20261020/`，此前基线保持原样。

局部复核通过 `POST /api/references/{asset_id}/repair` 指定 `base_analysis_id` 和 `targets`（`collection`、`index`、`issues`），只处理选段。已有帧、转写、切镜与未选段复用；同一区间在镜头细节和内容段两层共享一次调用。局部视觉请求不包含旧结论或语音，旁白另按本机词时间戳绑定；运镜复核增加连续帧及分布式背景位移证据，图像位移不等同于物理摄像机运动。各批独立缓存，失败不覆盖当前结果，过期版本不能覆盖新版本。

10月20日的人工核对版本仅用来定位问题，历史记录见 `output/reference-targeted-repair-20261020/局部修复前后对照.html`（4次调用、29,355 Token）。它不是产品的自动处理方式。

## DS 自动复核与声音节奏

最终判断仍由 DeepSeek 产生，未训练或微调模型。样片分析完成后，DS重新观察内容段的连续帧，再独立复核：背景在画面中的位移、人物相对背景的动作、观察视角、画面文字分别输出。程序校验引用时间、同镜头连续证据、文字与结构化结论是否矛盾；只把未通过的片段交回DS纠正，最多两轮。第二轮附上本机生成的同镜头帧组、顺序联系表及证据限制，开启DS深度思考。全局画面运动明显、模型又声称人物独立位移的片段，也在该轮单独核对；这是复核触发条件，不预设人物一定静止。没有人工答案进入这条自动流程，也不会把“工程校验通过”当作事实全部准确。

观察、复核、局部纠正各自保存输入指纹与来源；已有成功阶段复用，失败不覆盖当前结果。付费回复在JSON解析前保存原文，恢复必须原样解析并通过校验，不猜测补写。强度不同的调用独立缓存；人物动作不足、物理运镜方式不清晰时保留不确定。旁白独立按本机ASR词时间与片段求交，不再由视觉模型把整句或未来台词分配到当前镜头。

音频通过本机信号处理提取起音和具有周期支持的拍点候选，再将候选时间、实际切点、正负偏差及错位对照交给DS判断。界面“样片分析 → 声音”可查看两条时间轨、逐切点早晚偏差并定位原片。起音可能来自语音、噪声或音乐；邻近声音不等于有意卡点，未检出可靠周期时不强行标BPM。当前[DS Responses接口](https://api-docs.deepseek.com/api/create-response/)列出文字与图片输入，本流程未向DS发送原音，不能声称模型已听审音乐。

已有样片可通过 `POST /api/references/{asset_id}/rhythm` 单独补充节奏分析；新样片自动接入。两条样片的自动版对照、失败与重试回执、实际Token均保存在 `output/reference-auto-review-20261021/`；此前原片、切镜、转写和历史分析版本保留。

10月21日实测结果：长片局部复核23条记录，短片覆盖6个内容段及对应6条镜头细节，最终输出均来自DS自动链。短片5个切点中4个邻近周期候选（±100毫秒），末个偏晚约177毫秒；长片85个切点中74个邻近起音，但未检出可靠周期候选，不能由此认定稳定卡点。两片的DS节奏判断均为低置信度。运镜描述已拆开背景位移、主体动作和物理运镜证据；短片拍照亭段仍有“迈步”的可疑判断，ASR也仍有错字，当前结果不等于人工逐帧真值。完整前后对照见 [DS自动复核前后对照](output/reference-auto-review-20261021/DS自动复核前后对照.html)。

### 动画边界

首版为 2–60 秒、每段 2–30 秒、30 fps 的无声动态图形短片。源码自包含，不能读取本机文件或联网加载图片、字体、脚本；实际素材、配乐可在生成后进入现有剪辑流程组合。暂未接入配音驱动时序、外部图片/截图绑定、透明视频和复杂三维场景。数据对比只使用输入中给定的数字。每次模型调用保留实际 Token，逐帧渲染耗时保留在源版本审计中，均不冒充 H3 生成秒数。

10月21日真实 DeepSeek 验收完成两段共20秒、720p/30fps动画；自然语言修改第二段收尾文字后，仅更新对应源码和视频，第一段文件原样复用，两个完整版本均可播放。另与已有H3蓝色方块视频混剪为14秒成片；本轮未验证实拍素材混剪。实际14次模型调用共82,243 Token，含开发联调失败与重试，无新H3调用。源工程、用量、成片与检查边界见 [动画验收记录](output/qa/animation-20261021/acceptance.json)。

### 按剪辑组织方式展示

DeepSeek 在已有视觉复核和节奏结果之后，再判断样片主要依靠叙事、画面运动衔接、声音节奏还是并列场景组织；不以长短片时长直接决定类型，也不提供“开场建立”等旧模板角色作为分类答案。运动衔接允许不同场景以相似的屏幕位移、运动相位和构图接续，不要求同一人物连续完成动作。物理相机方向与画面背景位移分开。

已有样片可用 `POST /api/references/{asset_id}/presentation`，携带当前 `base_analysis_id` 单独补充。复用切镜、转录、视觉观察和节奏结果；连续帧补充只用于组织判读。运动转场节点引用实际镜头；叙事直接投影已有内容段，保留原始时间、描述和标签，镜头编号仅表示时间重叠，顺序连接不冒充模型推断的因果关系。两种单位不互相强制覆盖。运动节点的镜头编号、证据时间与相邻连接受真实镜头表校验；原答保留，失败时最多一次只纠正问题节点与受影响连接，不重发原始图片、不重写已通过字段。成功发布不可变新版本；后续视觉或节奏证据变化会使组织结果失效。校验通过不等于人工真值。

本轮图标、选材、信息卡片及两种真实样片展示的验收见 `output/qa/presentation-ui-20261021/acceptance.json`。6次实际回执共143,525 Token（含失败尝试及一份合成上传图分析），最终缓存恢复未新增调用，无新增H3。长片节点使用既有33内容段，失败的重组结果仅保留审计；短片使用6个实际镜头与5处运动连接。
